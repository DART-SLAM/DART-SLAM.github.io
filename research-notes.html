00

지금 결론

미팅 시작 직후 보여줄 핵심 판단만 남겼다.

Confirmed

SVO-DT 재현 자체는 성공

공식 Oerlikon 입력과 공개 설정으로 전체 파이프라인을 399.8초 실행했다.

Failed transfer

KIBO 전이는 실패

POST에서 world pose와 CAD registration이 모두 0. 실패 위치는 DT 정합 이전의 metric VIO다.

Supplementary

직접 headline 비교는 제외

SVO-DT는 RGB뿐 아니라 IMU와 지속적인 global position을 요구한다. KIBO 결과는 cross-domain stress로만 기록한다.

Current proof

DART 맵은 causal 두 구간

PRE와 POST를 각 시작 anchor의 metric gauge에서 독립 재구성해 연결했다. 자동 online resume 주장은 아직 하지 않는다.

Invalidated

Full-6DoF depth-ICP는 폐기

초기 변환 체인은 틀렸고, 공식 체인으로 다시 실행한 correction도 안전 gate가 7개 모두 거부했다.

Conditional

Plane normal만 후보로 유지

GT-blind 동결 뒤 유효 4개를 평가해 회전 3승 1패, 평균 −0.82°. 한 실패를 미리 구별하지 못해 아직 채택하지 않는다.

한 문장SVO-DT는 공식 조건에서 재현됐고 KIBO에서는 DT 정합 전에 VIO가 무너졌으며, 별도의 PicoFlex–CAD ICP도 공식 보정 후 신뢰 가능한 개선을 만들지 못했다.
01

SVO-DT 공식 재현

“재현 실패”가 아니라 공식 환경 재현 성공으로 분류한다.

Mono RGB+Filtered IMU+Ongoing global position+Metric twin→SVO-DTSensor depth

Global position은 시작 pose 한 번이 아니라 실행 중 계속 들어오는 절대 위치 측정이다. 공식 방법은 sensor depth를 사용하지 않는다.

한 평면의 한계. 평면 접선 이동 2축과 normal축 회전은 관측할 수 없다. 해당 3축은 기존 visual PnP/HI-SLAM2 prior에 남기고, depth는 보이는 방향만 covariance-weighted factor로 더한다.

확정된 결론

  • PicoFlex 원본과 XYZ parser는 정상
  • Raw cloud→full CAD 6DoF ICP는 폐기
  • Plane distance update도 폐기

남은 depth 후보

  • Normal-only factor를 visual prior와 융합
  • Rendered Pico-to-CAD + eigendirection gate
  • 강제 pose overwrite 없이 robust graph fusion
왜 dominant plane은 보조 factor로는 타당한가?
한 평면은 normal 방향 거리와 tilt만 제약하고, 평면 접선 이동 2축과 normal축 회전은 볼 수 없다. DART에서는 고정 CAD plane이 절대 기준이고 visual PnP/HI-SLAM2가 남은 자유도를 제공하므로, depth가 관측한 방향만 graph factor로 더하는 구성이 맞다. 한 RGB line과 한 depth plane으로 3DoF 절대 회전을 구한 Indoor RGB-D Compass, orthogonal plane을 이용한 Linear RGB-D SLAM, 관측 불가 방향을 초기 odometry에 남기는 X-ICP가 직접적인 설계 근거다. 반대로 joint-estimated monocular plane의 pose 개선은 제한적이라는 ICCVW 2023 분석도 있어, plane 자체를 만능 pose source로 취급하지 않는다.
판단ICP가 본질적으로 틀린 것이 아니라, partial single-depth를 full CAD에 6DoF로 강제한 구성이 틀렸다. 현재는 visual pose prior + plane-normal partial factor가 유망하고, 최종 후보는 visible rendered-depth residual을 관측 가능한 고유방향에만 넣는 방식이다.

05

연구 계보와 비교군

DART-SLAM을 만든 세 연구 흐름과, 실제 평가에서 각 방법이 맡는 역할을 분리한다.

01 · LOCAL MAPPING

Visual SLAM

HI-SLAM2 · VGGT-SLAM2 · MASt3R-SLAM

02 · GLOBAL POSE

3D-model-based visual localization

Retrieval · matching · pose estimation · HLoc · MeshLoc

03 · METRIC PRIOR

Digital-twin-aided SLAM

SVO-DT · diS-Graphs · ivS-Graphs · BIM-vSLAM

combined inDART-SLAM

단안 SLAM 백본에 metric twin 대상 render-to-real 위치추정과 검증된 구조 제약을 결합한다.
